纺织外贸跨境多智能体运营工作台（B2B牛仔面料外贸）
面向 B2B 牛仔面料外贸场景的多智能体运营工作台，基于 Spring Boot 3、Spring AI、RAG 向量库、多模态视觉、ASR/TTS 构建，支持文本询盘、语音询盘、面料图片询盘三条业务链路，并通过多 Agent 协同与 Review 校验抑制 AI 幻觉。

1. 项目简介
   本项目是一个面向纺织外贸跨境业务的智能运营工作台，重点服务牛仔面料 B2B 外贸询盘、报价、单证、竞品调研、交期预估、面料疵点识别和语音交互等场景。

系统以“规划调度 Agent”为总控，按业务任务调度竞品调研、询盘报价、单证合规、ERP 数据、面料视觉识别、AI 语音交互、Review 校验等子 Agent，结合 RAG 检索、Tool Calling、多模态视觉和 ASR/TTS 能力，形成从询盘输入到结果校验、前端展示、PDF 导出的完整闭环。

6. 系统分层架构图
![deepseek_mermaid_20260929_18f283.png](src%2Fmain%2Fresources%2Fassets%2Fdeepseek_mermaid_20260929_18f283.png)

架构说明
系统采用五层架构。前端工作台层承载询盘、竞品、报价、单证、图片疵点、语音和 PDF 导出等交互；应用服务层按业务用例封装服务能力，并统一接入权限、会话、文件与导出逻辑；多 Agent 智能层由规划调度 Agent 总控，负责询盘解析、任务拆解、子 Agent 调度和会话记忆，各子 Agent 分别承担竞品调研、报价、单证合规、ERP 查询、视觉识别、语音交互和 Review 校验；基础能力层提供 Spring AI 编排、RAG 向量库、多模态视觉、ASR/TTS、Tool Calling、MySQL、Redis、MinIO 等支撑；外部系统层对接现有纺织 ERP、海外供应商网站、报关合规知识源和邮件/消息通道。

整体数据流为：语音/图片/英文询盘进入前端，经应用服务层进入总控 Agent，按任务路由到子 Agent，调用 RAG、视觉、语音、Tool 和 ERP 能力，结果经 Review 校验后返回工作台，并支持 PDF 导出。

8. 多 Agent 询盘业务流程图

![deepseek_mermaid_20260929_743863.png](src%2Fmain%2Fresources%2Fassets%2Fdeepseek_mermaid_20260929_743863.png)

业务流程说明
业务员在工作台发起文本询盘、语音询盘或上传面料图片后，规划调度 Agent 统一接收并解析询盘意图，提取产品、数量、交期、单证、图片和语音诉求，完成任务拆解与路由。

文本类任务可直接进入竞品调研、报价、单证合规、ERP 查询等子 Agent；语音询盘先由 AI 语音交互 Agent 执行 ASR 语音转文字，并将文本意图回填调度 Agent 重新分发；图片询盘由面料视觉识别 Agent 执行多模态识别，输出面料品类、破洞、色差、跳纱、纬斜等疵点类型、位置和置信度。

各子 Agent 按需并行或串行执行 Tool 调用、RAG 检索、ERP 查询、图片识别和 ASR，生成竞品对比表、报价单、英文邮件、合规风险、交期和疵点报告等中间结果。全部结果汇总后交给 Review 校验 Agent，对报价、面料参数、图像识别和合规结论进行交叉校验；若校验不通过，则回退补充检索、重新调度或转人工确认，以抑制 AI 幻觉。校验通过后形成最终结果返回前端工作台，支持展示、编辑、PDF 导出，并可由 AI 语音交互 Agent 进行中英文 TTS 播报，业务员确认后发送或归档。

9. 关键设计说明
   9.1 总控调度
   规划调度 Agent 作为系统总控，负责统一接收文本、语音、图片输入，解析询盘意图，拆解任务并路由到对应子 Agent。同时维护会话记忆，保证多轮询盘上下文连续。

9.2 多 Agent 协同
各子 Agent 职责单一，按业务任务并行或串行执行。竞品调研、报价、单证、ERP、视觉、语音等 Agent 可独立扩展，互不耦合，通过统一结果协议汇总。

9.3 RAG 与 Tool 调用
单证合规 Agent 通过 RAG 检索报关、FOB/CIF、质检标准等知识；竞品调研、报价、ERP 数据 Agent 通过 Tool Calling 对接外部系统和 ERP，保证数据可追溯。

9.4 多模态与语音
面料视觉识别 Agent 支持面料品类识别和疵点检测；AI 语音交互 Agent 支持 ASR 语音转文字和 TTS 中英文播报，降低业务员操作成本。

9.5 Review 校验与幻觉抑制
Review 校验 Agent 对报价、面料参数、图像识别结果和合规结论进行交叉校验。校验不通过时，触发补充检索、重新调度或转人工确认，避免 AI 输出不可信结果。
